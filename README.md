# Docker Notes

A structured collection of self-prepared notes covering Docker fundamentals, architecture, container internals, and the core components used to build, run, network, and distribute containerized applications.

These notes were created while learning technologies and concepts used in modern application development and deployment, including the Java Full Stack ecosystem.

## Contents

| Topic | Description |
|---|---|
| [What is Docker and Why](Docker/What%20is%20Docker%20and%20Why.pdf) | Introduction to Docker, containerization, its purpose, and the deployment problems it addresses. |
| [Docker Architecture](Docker/Docker%20Architecture.pdf) | Client-server architecture and the interaction between Docker components. |
| [Docker Client and Daemon](Docker/Docker%20Client%20and%20Daemon.pdf) | The Docker CLI, daemon responsibilities, and how commands are handled. |
| [Docker Engine](Docker/Docker%20Engine.pdf) | Docker Engine components, APIs, and management of Docker objects. |
| [Docker Container](Docker/Docker%20Container.pdf) | Container fundamentals, image-to-container relationship, isolation, and lifecycle. |
| [Container Runtime](Docker/Container%20Runtime.pdf) | Container lifecycle management and the roles of containerd and runc. |
| [Namespaces and cgroups](Docker/Namespaces%20and%20cgroups.pdf) | Linux kernel mechanisms that provide process isolation and resource control. |
| [Docker Networking](Docker/Docker%20Networking.pdf) | Container networking and communication between application components. |
| [Docker Volumes](Docker/Docker%20Volumes.pdf) | Persistent storage, data sharing, and volume management. |
| [Docker Registry](Docker/Docker%20Registry.pdf) | Image repositories, tags, Docker Hub, and image distribution. |
| [Docker REST API and Image](Docker/Docker%20REST%20API%20and%20IMAGE.pdf) | Docker API communication and Docker image concepts. |

## Who Can Use These Notes?

- Students learning Docker and containerization.
- Java Full Stack learners exploring application packaging and deployment.
- Developers looking for a conceptual introduction to Docker architecture and components.
- Anyone revising the fundamentals of container-based application environments.

## How to Use

1. Clone or download this repository.
2. Open the PDF for the topic you want to study.
3. Follow the suggested learning path for a sequential introduction.
4. Practice the concepts with Docker commands and small containerized applications.

> **Note:** This repository contains learning notes for reference and revision. It is not an official Docker manual. For command syntax, version-specific behavior, and production guidance, consult the [official Docker documentation](https://docs.docker.com/).
